# Snusgården

En hemsida där kunder kan beställa snus som odlas på gården Hensbacka.

## Länkar

- Live: https://snusgarden.netlify.app
- Repo: https://github.com/illertriller/snusgarden

## Sidor

- index.html, startsida
- snus.html, alla produkter med filter
- garden.html, om gården
- bestall.html, beställningsformulär

## Tekniker

HTML, CSS (Flexbox, Grid, media query), JavaScript

## Funktioner

- mobilmeny
- filter
- varukorg
- validering

## Bilder

- Bilder på snusdosor är AI-genererade.
- Bilderna på fälten är AI-genererade men med mina egna bilder av tobaksplantor jag själv odlat, som grund.
- Bild på tobakslös med en hand som håller bladet, är min egen tagna bild.
- Bild på tobaksblad som torkar, hängandes i taket, är min egen tagna bild.
- Logotyper är också AI-genererade.
